# RAG-Based-AI-Application
Developed an AI application exploring Retrieval-Augmented Generation and intelligent information retrieval.

Features:

- Audio Transcription: Converts raw audio inputs (`.mp3`) into structured JSON files (`mp3_to_json.py`).
- Data Cleaning & Preprocessing: Preprocesses raw JSON payloads (`preprocess_json.py`) into clean format.
- Chunk Merging: Merges textual chunks (`merge_chunks.py`) into optimal context sizes for retrieval.
- Embedding Management: Generates and loads vector embeddings (`embeddings.joblib`) for efficient similarity searching.
- RAG Inference Engine: Takes user queries (`prompt.txt`), fetches relevant context, and outputs generated responses (`response.txt`).
